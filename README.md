TaskTracker

Descrição

O TaskTracker é uma aplicação de terminal desenvolvida em Python para cadastrar e visualizar tarefas.

Cada tarefa possui título, descrição, prioridade, data limite e status.

Funcionalidades

Cadastrar novas tarefas.

Validar o preenchimento do título.

Validar a prioridade entre Alta, Média e Baixa.

Definir automaticamente o status inicial como Pendente.

Listar as tarefas cadastradas.

Encerrar a aplicação pelo menu.

Tecnologias utilizadas

Python 3

Git

GitHub

Como executar

Instale o Python 3.

Abra o terminal na pasta do projeto.

Execute o comando:

python src/main.py

Se necessário, no Windows, utilize py src/main.py.

Observação

As tarefas ficam armazenadas em memória durante a execução. Ao encerrar o programa, elas não são salvas permanentemente.
